About the App

Joe's Speed Monitor uses a compatible external 25 Hz GPS receiver or your Android device's built-in GPS/GNSS location data to provide live vehicle speed and performance measurements.

It is designed for automotive enthusiasts, daily commuters, and performance drivers who want a simple way to monitor speed and record performance runs using their phone or tablet.

Features

  • Live GPS speed
  • Top-speed recording
  • Acceleration timing
  • 0–60 mph timing
  • 1/8-mile elapsed time
  • 1/8-mile trap speed
  • 1/4-mile elapsed time
  • 1/4-mile trap speed
  • External 25 Hz USB GPS support
  • Built-in Android GPS/GNSS support

Compatible External GPS Receiver

QUESCAN Android USB Type-C 25 Hz GPS Receiver

Joe's Speed Monitor supports the QUESCAN Android USB Type-C 25 Hz GPS receiver for faster and more frequent GPS updates than typical built-in phone GPS receivers.

The external receiver connects directly to a compatible Android phone or tablet using USB Type-C. When the receiver is connected and USB permission is granted, Joe's Speed Monitor can automatically use it as the GPS source for live speed and performance measurements.

  • Up to 25 GPS updates per second
  • USB Type-C connection
  • Automatically detected by Joe's Speed Monitor
  • Live vehicle speed measurement
  • 0–60 mph acceleration timing
  • 1/8-mile elapsed time and trap speed
  • 1/4-mile elapsed time and trap speed
  • Android phone GPS/GNSS remains available when the external receiver is not connected

Recommended for the best performance timing accuracy.
